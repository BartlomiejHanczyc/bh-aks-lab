# Kubernetes Lab

A personal DevOps lab project focused on building and running a scalable, cloud-native application infrastructure on Azure.

The planned architecture consists of:
- **Infrastructure:** Provisioned and managed using Terraform.
- **Backend:** .NET Web API.
- **Frontend:** Angular application.
- **Orchestration:** Kubernetes cluster with auto-scaling capabilities.
- **Database:** Azure SQL Database (MSSQL).
- **GitOps:** ArgoCD for continuous deployment.
- **Monitoring:** Prometheus and Grafana for metrics, monitoring, and visualization.
